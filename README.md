# Abu Sufiun Rhyme — Full Portfolio

A complete static portfolio website for GitHub Pages.

## Files
- `index.html` — portfolio content
- `style.css` — responsive design
- `script.js` — mobile navigation
- `images/profile.jpg` — profile image
- `CV.pdf` — CV

## Deploy with GitHub Pages
1. Create/open a GitHub repository.
2. Upload all files while keeping the `images` folder.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select `main` and `/root`.
6. Save and open the generated GitHub Pages URL.
